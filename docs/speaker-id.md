# 声纹注册 + 说话人识别：名人声音实验（2026-11-03）

> mentor 的设想：先明确告诉系统"这是谁的声音"（注册），再把几个人的声音拼在一起喂给它，看能不能认出来。
> 代码：`speaker_id.py`；完整结果：`benchmark/results/speaker_id.md`。

## 2. 结果

两个声纹模型（体积都约 38MB）：中文数据训练的 3D-Speaker ERes2Net（项目默认），和英文数据训练的 NeMo TitaNet small（对照）。

| 指标 | 3D-Speaker（中文） | TitaNet（英文） |
|---|---|---|
| 整条识别（17 条已注册 + 7 条陌生人） | **24/24** | **24/24** |
| 陌生人被错认 | 0 | 0 |
| 1s 片段准确率 | 52% | 58% |
| 2s 片段准确率 | 81% | 90% |
| 3s 片段准确率 | 89% | 94% |
| 5s 片段准确率 | 98% | 98% |
| 3s 片段：同一人 / 不同人平均相似度 | 0.62 / 0.15 | 0.70 / 0.03 |
| 等错误率 EER（推荐阈值） | 3.1%（0.41） | 1.5%（0.33） |
| **拼接场景：分角色切段 + 认人**（按时长计标对的比例） | **82.3%** | **86.7%** |
| 拼接场景：1.5s 滑动窗口逐窗认人（对照） | 53.8% | 68.0% |

拼接场景：9 个已注册的人加 1 个陌生人，每人约 10s 依次拼接、中间只隔 0.5s，两轮共 183s。

### 马斯克 / 黄仁勋 结果

两人都是**英文原声**，来自 B 站公开视频，注册和测试各用一个不同的视频（清单见 `benchmark/speakers/clips.tsv`）：

| 人 | 注册（10s） | 测试（18s） | 3D-Speaker（中文模型） | TitaNet（英文模型） |
|---|---|---|---|---|
| 马斯克 | 艾萨克森采访 9:46–9:56 | 央视财经专访 5:06–5:24 | ✅ musk，相似度 **0.590**（第二像 tom 仅 0.238，与 jensen 0.057） | ✅ musk，**0.583**（第二像 leijun 0.119，与 jensen 0.012） |
| 黄仁勋 | NVIDIA GTC 2026 主题演讲 31:13–31:23 | 卡内基梅隆毕业典礼演讲 6:28–6:46 | ✅ jensen，**0.629**（第二像 deniro 0.424，与 musk 0.134） | ✅ jensen，**0.697**（第二像 deniro 0.217，与 musk 0.004） |

1. **中文声纹模型认英文人声没问题**：两人的整条测试音频在两个模型上都认对了，两人的声纹也没有互相混淆（马斯克→jensen 只有 0.057/0.012）。
2. **相似度比母语样本低**：两人 0.58–0.70，而 tortoise 的演员和雷军是 0.67–0.88。名人音频是访谈/演讲现场，混响和底噪更差；央视那段访谈的静音段约 −32 dBFS（有背景音乐垫），而注册用的艾萨克森采访静音段 −56 dBFS（干净）。
3. **访谈片段要先挑单人时段**：主持人的提问会把声纹污染，所以先用分角色模型确认窗口内只有一个人再截取——这 4 段窗口的说话人纯度都是 100%。
4. **拼接场景里两人也认得出，但交界处会掉**：分角色切出来的段里有几条被拒认（相似度 0.43–0.47，卡在 0.5 阈值下），集中在换人交界和不足 2s 的碎段。

## 3. 结论

1. **注册后认人基本可用**：24 条整条测试音频（4.7–18s）两个模型全对，7 段陌生人一条都没被错认；3s 片段 89–94%，5s 98%。
2. **片段至少要 2 秒**：1 秒的片段只有 52–58% 能认对；2 秒升到 81–90%。家庭场景里一两个字的应答（"嗯""好的"）认不出是谁，需要结合上下文判断。
3. **拼接场景必须先找"换人"的边界**：0.5s 的停顿 VAD 切不开，会把相邻两个人粘成一段。先用分角色模型（pyannote）切出说话人段再认人，按时长计准确率 82–87%；直接用滑动窗口只有 54–68%。错误集中在说话人交界处和不到 1s 的碎段。
4. **英文模型在英文人声上更好**（EER 1.5% 对 3.1%），**但中文模型对雷军、马斯克、黄仁勋的整条识别也全对**。机器人面向中文家庭，默认保留中文 3D-Speaker；如果有英文使用场景，可以两个模型都打分。
5. **阈值**：默认 0.5 在本数据上整条全对；EER 推荐值是中文 0.41 / 英文 0.33，但用 0.41 时中文模型会把一个陌生人（daniel）错认成 deniro（相似度 0.47）。家庭场景里"认错人"比"没认出来"更糟，**建议阈值取 0.5 左右，宁可拒认**。

## 4. 局限

- 名人音频是访谈/演讲现场，和机器人实际听到的远场、带噪声的家庭录音差距很大；央视那段访谈还带背景音乐垫。
- 马斯克、黄仁勋各只有 2 段（1 注册 + 1 测试），样本偏少；两人的片段都是英文，手册里"黄仁勋讲中文的片段"（跨语种）本轮没做——B 站上他的中文素材多是带解说的剪辑，没找到干净单人的。
- 其余人每人只有 2–4 段，陌生人 2 位。

## 5. 复现

```bash
python download_models.py                                                   # 含中文声纹模型、分角色模型、VAD
python download_models.py --models speaker-embedding-en --no-diarization    # 可选：英文声纹模型
python tools/fetch_speaker_clips.py                                         # 按 benchmark/speakers/clips.tsv 下载并截取
python speaker_id.py
```

B 站链接在视频页被风控（HTTP 412）时会自动改走官方接口取音频直链（`tools/bilibili.py`），不用额外配置；YouTube 链接需要能直连的网络。
