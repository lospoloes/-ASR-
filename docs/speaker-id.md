# 声纹注册 + 说话人识别：名人声音实验（2026-11-03）

> mentor 的设想：先明确告诉系统"这是谁的声音"（注册），再把几个人的声音拼在一起喂给它，看能不能认出来。
> 代码：`speaker_id.py`；完整结果：`benchmark/results/speaker_id.md`。

## 1. 数据

原计划用马斯克、黄仁勋的公开视频。运行环境访问不了 YouTube、B 站、维基、archive.org，搜索工具也不提供特定真人的声音样本，所以改用 GitHub 上开源项目自带的公开参考音频：

| 人 | 来源 | 注册 | 测试 |
|---|---|---|---|
| deniro、emma、freeman、halle、jlaw、tom（6 位好莱坞演员，英文） | [tortoise-tts](https://github.com/neonbjb/tortoise-tts/tree/main/tortoise/voices) 自带的参考音频。目录名对应的演员（德尼罗、艾玛·斯通、摩根·弗里曼、哈莉·贝瑞、詹妮弗·劳伦斯、汤姆·汉克斯）是社区通行说法，**未核实** | 第 1 段（约 10s；emma 用第 1、2 段） | 其余 2–3 段 |
| 雷军（中文） | sherpa-onnx 的 lei-jun-test.wav（272s 演讲） | 演讲 30–60s | 演讲 200–240s；另加 ZipVoice 自带的 leijun-1.wav |
| 陌生人（不注册）：daniel、weaver（英文）、两段新闻女主播（中文） | tortoise-tts；ZipVoice test_wavs | — | 共 9 段，应被拒绝 |

**注意**：
- ZipVoice 里的 leijun-1.wav 经互相关检验，与演讲 145s 处是**同一段录音**（相关系数 0.465）。所以雷军的注册和测试都来自同一场演讲，结果偏乐观。
- tortoise 同一个人的几段音频是否来自不同视频，无法确认。
- 音频只放在 `test_audio/`（不提交），来源记录在 `test_audio/speakers/sources.tsv`。

## 2. 结果

两个声纹模型（体积都约 38MB）：中文数据训练的 3D-Speaker ERes2Net（项目默认），和英文数据训练的 NeMo TitaNet small（对照）。

| 指标 | 3D-Speaker（中文） | TitaNet（英文） |
|---|---|---|
| 整条识别（16 条已注册 + 9 条陌生人） | **25/25** | **25/25** |
| 陌生人被错认 | 0 | 0 |
| 1s 片段准确率 | 63% | 61% |
| 2s 片段准确率 | 90% | 98% |
| 3s 片段准确率 | 95% | 99% |
| 5s 片段准确率 | 98% | 100% |
| 3s 片段：同一人 / 不同人平均相似度 | 0.66 / 0.16 | 0.72 / 0.03 |
| 等错误率 EER（推荐阈值） | 2.0%（0.43） | 0.3%（0.40） |
| **拼接场景：分角色切段 + 认人**（按时长计标对的比例） | **91.1%** | **91.7%** |
| 拼接场景：1.5s 滑动窗口逐窗认人（对照） | 72.2% | 81.1% |

拼接场景：7 个已注册的人加 1 个陌生人，每人约 10s 依次拼接、中间只隔 0.5s，两轮共 143s。

## 3. 结论

1. **注册后认人基本可用**：整段音频（5s 以上）两个模型都全对，陌生人一个都没被错认。
2. **片段至少要 2 秒**：1 秒的片段只有约 60% 能认对；2 秒升到 90% 以上。家庭场景里一两个字的应答（"嗯""好的"）认不出是谁，需要结合上下文判断。
3. **拼接场景必须先找"换人"的边界**：0.5s 的停顿 VAD 切不开，会把相邻两个人粘成一段。先用分角色模型（pyannote）切出说话人段再认人，按时长计准确率约 91%；直接用滑动窗口只有 72–81%。错误集中在说话人交界处和不到 1s 的碎段。
4. **英文模型在英文人声上更好**（EER 0.3% 对 2.0%），**中文模型对雷军也全对**。机器人面向中文家庭，默认保留中文 3D-Speaker；如果有英文使用场景，可以两个模型都打分。
5. **阈值**：默认 0.5 在本数据上整条全对；EER 推荐值是 0.40–0.43，但用 0.43 时中文模型会把一个陌生人（daniel）错认成 deniro（相似度 0.47）。家庭场景里"认错人"比"没认出来"更糟，**建议阈值取 0.5 左右，宁可拒认**。

## 4. 局限

- 名人音频是开源项目里截好的干净片段，和机器人实际听到的远场、带噪声的家庭录音差距很大。
- 样本少：每人只有 2–4 段，陌生人 4 位。
- 马斯克、黄仁勋的音频在这边拿不到；要测他们，需要在能访问 YouTube 的电脑上下载，放进 `test_audio/speakers/` 后运行 `python speaker_id.py`。

## 5. 复现

```bash
python download_models.py                                                   # 含中文声纹模型、分角色模型、VAD
python download_models.py --models speaker-embedding-en --no-diarization    # 可选：英文声纹模型
# 按 README「声纹注册 + 说话人识别」一节把音频放进 test_audio/speakers/
python speaker_id.py
```
