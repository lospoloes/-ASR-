# 声纹注册 · 主人识别

持续监听 ASR 的可选能力：注册主人声纹后，每条正式转写结果带 `owner` 字段（true 主人 / false 陌生人 / null 判不了），转写内容不动。

## 用法

```bash
# 1. 注册（音频任意格式，建议 2 句以上、每句 ≥5 秒；不提交）
python tools/enroll_owner.py --name 老板 --files a.wav b.wav

# 2. 重启 server：检测到 data/owner_profile.json + ERes2Net 模型就自动启用
# 3. 页面正式结果旁显示 主人 / 陌生人 / 未知 徽标；不注册就是普通模式，无 owner 字段
```

## 规则

- **<3 秒（主人声纹有效段累积）不判**：句内 Diarizer 切说话人段，取与主人声纹最像的主段向量按秒数加权攒（跨句累积），攒够 3 秒判一次后清零；攒不够发 `null`（`MIN_SEC=3.0`）；
- 判定用分角色**主段**音频（不是整句）：多句对话里只认主人说话的段；
- 注册向量用**全长**音频（离线注册不赶时间）；
- **双阈值**（开发集曲线定的，验证集未调参）：对话档 `0.45`（FAR 1.4% / FRR 0%，主人少被拒，日常显示）、特权档 `0.55`（FAR 0.3% / FRR 12.1%，敏感操作宁拒）；
- 前置条件：声纹模型 + 说话人分离（pyannote-seg）模型都已下载。

## 验证（真实数据，deniro 注册）

- 对话档 0.45：FAR 0/21 = 0%（陌生人 10 人 21 句，验收 ≤1%）；≥3s 主人召回 3/3 = 100%（验收 ≥90%）；
- 特权档 0.55：FAR 0/21；召回 1/3（以召回换严格，敏感操作用）；
- 反向：`eval_owner.py --shuffle` 打乱注册向量后 FAR 52.4%（期望 ~50%，见 owner_eval.md）；
- 引擎对比：ERes2Net 与 TitaNet 同集合都召回 3/3、FAR 0/21，保留 ERes2Net（zh-cn 契合）。
