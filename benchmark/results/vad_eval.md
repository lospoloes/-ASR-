# VAD 评测：真人双人对话（MagicData-RAMC 整段）

- 数据：3 段 dev 集对话，共 94 分钟、1647 句人工标注（其中 <0.8s 的短句 249 句）；标注里有声音的时间占 84%。音频和文本只在本机（CC BY-NC-ND 4.0），这里只有统计数字
- 方法：`tools/eval_vad.py`。逐帧人声概率用 `vad_stream`（与 sherpa-onnx 逐帧等价）算一遍，各组参数重放切分；现状 = 阈值 0.5、静音阈值 0.35（= 阈值 − 0.15）、最短开口 0.25s、句末静音 0.5s、句长上限 15s、段停顿 0.2s / 段 ≥1s / 段长上限 8s、自动增益开
- 开口延迟只统计前面 ≥1s 没人出声的句子（212 句），判停延迟只统计后面 ≥1s 没人出声的句子（209 句）；标注起止本身有零点几秒误差，看中位数、P90 和组间差
- 误检：VAD 判为说话、离所有声音标注（含笑声、听不清）都 >0.3s 的时长；漏检：标注句被覆盖不到一半
- 估算算力：蹦字每 0.5s 一次，SenseVoice 每次解码按 28ms + 16ms/秒音频（M4 Pro 实时回放实测拟合），额外解码 =（蹦字 + 段锁定）/ 正式结果；假设转写线程跟得上
