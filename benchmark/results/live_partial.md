# 临时出字：真人双人对话按真实速度回放

- 数据：`CTS-CN-F2F-2019-11-15-1434_13-190.wav`（177s，53 句人工标注）按真实速度推给 `/ws/live`，和网页推流一样 0.1s 一块；记下每个事件到达的时刻（`python tools/replay_live.py`）
- 静音阈值 0.5s，最长 chunk 15.0s；两个模型在同一个转写线程里依次跑（和网页 demo 一样）；机器：Darwin arm64（Apple M4 Pro），每个模型 2 线程
- **开口后见字**：一句话（VAD 切出的 chunk）开始 → 屏幕上出现这句的第一个字（临时或正式）
- **说话时屏幕落后**：有人在说话的每个时刻（按人工标注，每 0.1s 取一点），屏幕上的字只识别到了多少秒之前的话
- **最长没有新字**：这一栏相邻两次更新之间的最长间隔（和 3.1 节的 16.9 秒同一口径）
- **正式结果出字**：VAD 判定说完 → 正式结果到达（含排队；开临时结果时可能要等手上那次临时识别做完）
- **额外解码**：所有临时识别的解码耗时之和，是正式结果解码耗时之和的几倍；**转写占用**：全部解码耗时 / 音频时长
- **灰字被改**：临时结果里的字，后来被下一次临时结果或正式结果改掉的比例（去标点后按字比）
